# Changelog

All notable changes to the Aimer CLI (`aimer`) are documented here.

This file is only the index. The full release notes for each version live in
[`changelogs/`](changelogs/), one file per version, named `<version>.md`. Open the
version you care about from the table of contents below.

## Versioning

Releases use a calendar-style scheme, `YY.MINOR.PATCH`, with an optional pre-release
suffix such as `-dev.N` for builds that are still in development. Newer versions are
listed first.

## Table of contents

| Version                                   | Status      | Highlights                                                  |
|-------------------------------------------|-------------|-------------------------------------------------------------|
| [26.0.0-dev.2](changelogs/26.0.0-dev.2.md) | Development | `aimer input`, `aimer screenshot` and MCP tools to drive and see the running app, `update` and `components` commands |

## Adding a new release

1. Create `changelogs/<version>.md` with the notes for that release.
2. Add a row at the top of the table above, linking to the new file.
3. Keep the highlights to one line; put the details in the version file.
